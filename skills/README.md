## Add a procedure

Copy `check-transaction/en.md` into a uniquely named item folder; the section-and-folder path is the shared knowledge identity. Include prerequisites, numbered steps, verification, and what to do when the result is unexpected. Describe an agent path only when it adds something useful. See [Contributing](../CONTRIBUTING.md).
