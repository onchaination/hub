Understand something before you act. Start with plain-language explanations of how onchain systems work.

## Add an explanation

Copy `transaction/en.md` into a uniquely named item folder and keep one clear question in mind. The folder name is the stable content ID. A useful explanation includes a mental model, a concrete example, and a way to check understanding. See [Contributing](../CONTRIBUTING.md).
