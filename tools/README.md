## Add a tool

Copy `network-fee-calculator/en.md` into a uniquely named item folder; the section-and-folder path is the shared knowledge identity. Explain what the tool does, its inputs, its limits, and a useful example. Widgets are optional; a good guide to an existing interface is welcome. See [Contributing](../CONTRIBUTING.md).
